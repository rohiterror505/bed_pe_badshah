Place your audio files in this directory following the structure below.
The game gracefully ignores missing files and runs silent if none are present.

```
public/audio/
  amitabh/
    kill-01.mp3
    kill-02.mp3
  puneet/
    entrance-01.mp3
    miss-01.mp3
  rakhi/
    entrance-01.mp3
    miss-01.mp3
  mc-stan/
    entrance-01.mp3
    taunt-01.mp3
  effects/
    shoot.wav
    hit.wav
    explosion.wav
    combo.wav
  music/
    background.mp3
```

Supported formats: MP3, WAV, OGG.

Only use recordings you own, have licensed, or that are original parody
voice work. Do NOT clone or scrape real celebrity voices without
authorization.
